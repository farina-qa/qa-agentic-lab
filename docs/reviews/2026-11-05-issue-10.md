# Devil's advocate review: issue #10

## Findings

1. **Fourth criterion is unverifiable** (#10 AC: "The order I choose is
   applied to the list I see"). It restates criteria 2 and 3 and names no
   observable. A test case built on it has no expected result of its own and
   will either duplicate TC steps or assert nothing. Fix: delete it, or state
   one observable, e.g. the list matches the chosen option after selection.

2. **Sort order is undefined for ties** (#10 AC: "sort by price, low to
   high"). If two products share a price, both orders are "correct"; the
   expected sequence is then left to whoever writes the assertion, and a
   spec can pass or fail on an arbitrary choice. Fix: add "products with
   equal prices may appear in either order", or name the tiebreak.

3. **"Image" has no pass condition** (#10 AC: "each with a name,
   description, price and image"). A broken or placeholder image still
   "has an image", so a rendering defect passes the criterion. Fix: say the
   image is displayed, not broken.

4. **Default order is unstated** (#10 Story and AC). No criterion says what
   order I see before choosing, so "sorting reorders" has no starting state
   to compare against. Fix: add one criterion naming the initial order.

## Also noticed

- #10 leaves #9's add/remove and cart-badge criteria without a story; this
  is already reported in `docs/reviews/2026-09-03-issue-9-rerun.md`, so I
  treat it as a reference.
- `docs/traceability.md` has no section for #9 and #10 yet; acceptable until
  a test case exists.

## In its favour

The story block carries a real motive ("compare items before adding them to
my cart") and the first-person criteria follow `docs/writing-tickets.md`.
Parent #9, `area:inventory` and the Phase 2 milestone all agree with
`docs/plan.md`, so the chain resolves. I nearly objected to the hardcoded
"six products", but it matches #9 and is gradable as written.

## Verdict

**Objections.** I tried to find harness bleeding, a prescribed
implementation and a wrong phase; none held. The defects are one
unverifiable criterion and two undefined expected results.
